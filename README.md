# Excel Dental of Greentree

Static, responsive website for Excel Dental of Greentree in Pittsburgh, PA.

## Preview locally

From the repository root, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then open `http://localhost:8000`.

The site uses plain HTML, CSS, and JavaScript. `index.html` is the practice landing page, `about.html` introduces Dr. Kancharla, and `contact.html` contains the office's contact information and hours. Appointment requests are made by phone.
